비상 운영 키트

1. 사전 준비

비상 기록을 이 기기에 보관합니다

행사 정보 준비 중…

인쇄 창에서 ‘PDF로 저장’을 선택하면 인터넷 없이 열 수 있는 운영 문서를 만들 수 있습니다.

2. 온라인 비상 투표

외부 비상 투표 링크

링크는 이 관리자 브라우저에만 저장됩니다. 행사 전 인쇄 키트와 외부 투표 QR을 함께 준비해 주세요.

3. 장애 발생 시

정상 투표와 비상 투표를 동시에 열지 마세요

  1. 관리자 두 명이 광장과 투표 오류를 각각 확인하고 시작 시각을 기록합니다.
  2. 관리자 화면이 열리면 정상 투표를 먼저 중단하고, 현재 기록 CSV를 저장합니다.
  3. 외부 비상 투표 또는 인쇄된 종이 투표지 한 가지 방식으로만 전환합니다.
  4. 복구 뒤에는 비상 투표를 먼저 마감한 다음, 기록을 대조하고 정상 투표를 재개합니다.

현재 QR은 게임 상세 페이지용입니다. Worker 전체 장애까지 대비하려면 비상 키트에 들어가는 게임 직접 주소도 행사 전에 별도로 확인해 주세요.
